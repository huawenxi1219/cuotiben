第一章 物质及其变化
物质分类与转化（章末图 · 深度版）
　混合物 · 胶体
先按分散质粒子直径分，再看分散剂与分散质。
  • 分类
    • 按分散剂状态 　气溶胶（烟、雾） 　液溶胶（Fe(OH)₃ 胶体） 　固溶胶（有色玻璃）
    • 按分散质构成 　粒子胶体：分散质为许多分子集合体 　分子胶体：分散质为单个大分子（如蛋白质溶液）
  • 氢氧化铁胶体的制备
    • 原理 　FeCl₃ + 3H₂O →(Δ) Fe(OH)₃(胶体) + 3HCl
    • 操作 　向沸水中逐滴加入饱和 FeCl₃ 溶液 　继续煮沸至液体呈红褐色，立即停止加热
    • 现象 　得到红褐色透明液体
    • 注意事项 　不能用 NaOH 代替 　不能长时间煮沸（会聚沉） 　不能搅拌
  • 性质
    • 丁达尔效应 　光通过胶体出现光路 　用于区分溶液和胶体 　属于物理现象
　纯净物 · 单质
  • 金属单质 　Na、Mg、Al、Fe、Cu 等
  • 非金属单质 　Cl₂、O₂、S、N₂、Si 等
  • 稀有气体 　He、Ne、Ar 等，单原子分子
　纯净物 · 化合物
  • 有机化合物 　含碳的化合物（CO、CO₂、碳酸盐除外）
  • 无机化合物 · 酸
    • 按电离出 H⁺ 数目 　一元酸（HCl、CH₃COOH） 　二元酸（H₂SO₄、H₂CO₃） 　三元酸（H₃PO₄）
    • 按酸性强弱 　强酸：HCl、H₂SO₄、HNO₃ 　弱酸：CH₃COOH、H₂CO₃、HClO
    • 按有无挥发性 　挥发性酸：HCl、HNO₃ 　难挥发性酸：H₂SO₄、H₃PO₄
    • 按溶解性 　可溶性酸 　难溶性酸（H₂SiO₃）
  • 无机化合物 · 碱
    • 按溶解性 　可溶性碱：NaOH、KOH、Ba(OH)₂ 　难溶性碱：Fe(OH)₃、Cu(OH)₂、Mg(OH)₂
    • 按碱性强弱 　强碱：NaOH、KOH、Ba(OH)₂ 　弱碱：NH₃·H₂O
  • 无机化合物 · 盐
    • 按组成 　正盐（Na₂CO₃） 　酸式盐（NaHCO₃） 　碱式盐（Cu₂(OH)₂CO₃）
    • 按溶解性 　可溶性盐 　难溶性盐（BaSO₄、AgCl）
  • 无机化合物 · 氧化物
    • 按组成 　金属氧化物（Na₂O、Fe₂O₃） 　非金属氧化物（CO₂、SO₂）
    • 按性质 　酸性氧化物（CO₂、SO₃） 　碱性氧化物（Na₂O、CaO） 　两性氧化物（Al₂O₃） 　不成盐氧化物（CO、NO）
　分类方法
  • 树状分类法 　逐级细分，如 物质→混合物/纯净物→…
  • 交叉分类法 　同一物质同时属于多个类别（Na₂CO₃ 既是钠盐又是碳酸盐）
　化学反应分类 · 基本反应类型
  • 化合反应 　A + B → AB
  • 分解反应 　AB → A + B
  • 置换反应 　A + BC → AC + B（一定是氧化还原）
  • 复分解反应 　AB + CD → AD + CB（生成沉淀/气体/弱电解质）
　离子反应
  • 离子方程式书写
    • 改写 　拆：强酸、强碱、可溶盐 　不拆：弱电解质、沉淀、气体、氧化物、单质
    • 直写 　按离子形式直接写，再配平
  • 意义 　表示同一类反应，而不只是一个具体反应
  • 发生条件 　生成沉淀 　放出气体 　生成难电离的物质（水、弱酸、弱碱） 　发生氧化还原反应
  • 应用 · 离子共存 　生成沉淀不能共存 　生成气体不能共存 　生成弱电解质不能共存 　发生氧化还原不能共存 　注意隐含条件：无色、酸性、碱性
　氧化还原反应
  • 实质 　电子转移（得失或偏移） 　双线桥法：标得失电子数 　单线桥法：标电子转移方向与数目
  • 特征 　元素化合价升降（宏观判断依据）
  • 基本概念
    • 氧化剂与还原剂 　氧化剂：得电子、化合价降低、被还原 　还原剂：失电子、化合价升高、被氧化
    • 产物 　氧化剂 → 还原产物 　还原剂 → 氧化产物
  • 配平方法 　标变价 　列得失 　求总数（最小公倍数） 　配系数 　查守恒（质量、电荷、电子）
  • 规律总结
    • 守恒规律 　得失电子总数相等
    • 强弱规律 　氧化性：氧化剂 > 氧化产物 　还原性：还原剂 > 还原产物
    • 价态规律 　最高价只有氧化性 　最低价只有还原性 　中间价态两者都有
    • 先后规律 　还原性强的先被氧化 　氧化性强的先被还原
  • 信息型方程式书写 　先由信息确定产物与价态 　再按配平五步走
　物质的转化
  • 从物质类别角度
    • 酸的通性 　使酸碱指示剂显色 　与活泼金属反应（置换） 　与碱性氧化物反应（复分解） 　与碱反应（复分解） 　与某些盐反应（复分解）
    • 碱的通性 　使酸碱指示剂显色 　与酸性氧化物反应 　与酸反应 　与某些盐反应
    • 盐的通性 　与金属反应（置换） 　与碱反应 　与酸反应 　与某些盐反应
  • 从元素价态角度 　最高价态：只有氧化性 　最低价态：只有还原性 　中间价态：既有氧化性又有还原性
第二章 海水中的重要元素——钠和氯
物质的量（章末图 · 深度版）
　物质的量
  • 符号与单位 　符号 n 　单位 摩尔（mol）
  • 使用范围 　只用于微观粒子（分子、原子、离子、电子、质子、中子） 　或它们的特定组合（原子团、官能团）
　阿伏加德罗常数
  • 概念 　1 mol 任何粒子的粒子数
  • 数值 　N_A ≈ 6.02×10²³ mol⁻¹
  • 公式 　n = N / N_A 　N = n · N_A
　摩尔质量
  • 概念 　单位物质的量的物质所具有的质量
  • 数值 　以 g/mol 为单位时，数值上等于相对分子（原子）质量
  • 公式 　M = m / n
　气体摩尔体积
  • 概念 　单位物质的量的气体所占的体积
  • 单位 　L/mol 或 L·mol⁻¹ 　m³/mol 或 m³·mol⁻¹
  • 公式 　Vm = V / n
  • 特例 　标准状况（0 ℃，101 kPa）下 Vm ≈ 22.4 L/mol
　阿伏加德罗定律
  • 含义 　同温同压下，相同体积的任何气体都含有相同数目的粒子
  • 三同定一同 　T₁=T₂、p₁=p₂、V₁=V₂ ⇒ N₁=N₂
  • 推论 　同温同压：V₁/V₂ = n₁/n₂ 　同温同体积：p₁/p₂ = n₁/n₂
　物质的量浓度
  • 定义 　单位体积溶液里所含溶质 B 的物质的量
  • 表达式 　c_B = n_B / V
  • 单位 　mol/L 或 mol·L⁻¹
  • 配制一定物质的量浓度溶液
    • 仪器使用 　容量瓶：不能加热、不能作反应容器 　定容时用胶头滴管
    • 操作步骤 　计算 → 称量 → 溶解 → 冷却 → 转移 → 洗涤 → 定容 → 摇匀
    • 误差分析 　n 偏小 → c 偏小（如溶质损失、未洗涤） 　V 偏小 → c 偏大（如俯视定容）
　化学计算常用方法
  • 守恒法 　电子守恒、原子守恒、电荷守恒
  • 关系式法 　多步反应找比例关系
  • 差量法 　看质量或体积的变化量
  • 热重分析法 　看加热过程中的失重
第三章 铁 金属材料
金属及其化合物（章末图 · 深度版）
　钠
  • 物理性质 　银白色、质软、密度小于水大于煤油、熔点低
  • 与氧气 　常温：4Na + O₂ → 2Na₂O 　加热：2Na + O₂ →(Δ) Na₂O₂，黄色火焰
  • 与水 　2Na + 2H₂O → 2NaOH + H₂↑ 　现象：浮、熔、游、响、红
  • 与酸 　比与水更剧烈，直接置换 H₂
  • 与盐溶液 　先与水反应，再考虑沉淀 　不能直接置换出金属
　钠的氧化物
  • 氧化钠 Na₂O 　碱性氧化物 　Na₂O + H₂O → 2NaOH 　Na₂O + CO₂ → Na₂CO₃
  • 过氧化钠 Na₂O₂ 　氧为 −1 价，强氧化性 　2Na₂O₂ + 2H₂O → 4NaOH + O₂↑ 　2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂ 　供氧剂、漂白剂
　碳酸钠与碳酸氢钠
  • 四个比较 　碱性：Na₂CO₃ > NaHCO₃ 　溶解性：Na₂CO₃ > NaHCO₃ 　热稳定性：NaHCO₃ 分解 　与酸反应：NaHCO₃ 更快
  • 鉴别 　固体加热法 　溶液测 pH 　加盐酸法 　加 BaCl₂ 法
  • 侯氏制碱 　先通 NH₃ 后通 CO₂ 　NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl
　焰色试验
  • 操作 　洗→烧→蘸→烧→洗 　用盐酸洗铂丝
  • 现象 　钠：黄色 　钾：紫色（透过蓝色钴玻璃）
　铁
  • 位置与价态 　第四周期第Ⅷ族 　常见 +2、+3
  • 与非金属 　Cl₂ → FeCl₃ 　S → FeS 　I₂ → FeI₂
  • 与水蒸气 　3Fe + 4H₂O(g) →(高温) Fe₃O₄ + 4H₂
  • 与酸 　非氧化性酸 → Fe²⁺ 　氧化性酸 → Fe³⁺ 　铁过量最终 Fe²⁺
  • 与盐溶液 　Fe + Cu²⁺ → Fe²⁺ + Cu
　铁的氧化物与氢氧化物
  • 氧化物 　FeO：黑色，不稳定 　Fe₂O₃：红棕色（铁红） 　Fe₃O₄：黑色，有磁性
  • 氢氧化物 　Fe(OH)₂：白色→灰绿→红褐 　Fe(OH)₃：红褐色，受热分解
　铁盐与亚铁盐
  • Fe³⁺ 检验 　KSCN 变红 　NaOH 红褐色沉淀 　苯酚显紫色
  • Fe²⁺ 检验 　加 KSCN 无现象，再加氯水变红 　NaOH 白色→灰绿→红褐
  • 转化 　2Fe³⁺ + Fe → 3Fe²⁺ 　2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻
　铝及其化合物
  • 两性 　2Al + 6H⁺ → 2Al³⁺ + 3H₂↑ 　2Al + 2OH⁻ + 2H₂O → 2AlO₂⁻ + 3H₂↑
  • 氧化物与氢氧化物 　Al₂O₃ 两性 　Al(OH)₃ 两性：溶于强酸强碱，不溶于氨水
  • 铝热反应 　2Al + Fe₂O₃ →(高温) 2Fe + Al₂O₃
　铜与金属冶炼
  • 铜 　Cu + 2Fe³⁺ → Cu²⁺ + 2Fe²⁺ 　与浓硝酸、稀硝酸产物不同
  • 冶炼方法 　电解法：K Ca Na Mg Al 　热还原法：Zn Fe Sn Pb Cu 　热分解法：Hg Ag
第四章 物质结构 元素周期律
物质结构与元素周期律（章末图 · 深度版）
　原子结构
  • 构成 　质子数决定元素种类 　质量数 A = Z + N
  • 同位素 　质子数相同、中子数不同 　化学性质几乎相同
  • 核外电子排布 　分层排布，每层最多 2n² 　最外层不超过 8
　元素周期表
  • 结构 　7 个周期、16 个族 　周期序数 = 电子层数
  • 主族 　主族序数 = 最外层电子数
　元素周期律
  • 原子半径 　同周期从左到右减小 　同主族从上到下增大
  • 金属性/非金属性 　同周期左→右金属性减弱 　同主族上→下金属性增强
  • 判断依据 　金属性：与水/酸反应难易、最高价氧化物水化物碱性 　非金属性：氢化物稳定性、最高价含氧酸酸性
　化学键
  • 离子键 　阴阳离子间静电作用 　离子化合物：NaCl、Na₂O、NaOH
  • 共价键 　共用电子对 　共价化合物：HCl、H₂O、CO₂
  • 分子间作用力 　范德华力、氢键 　氢键使水沸点异常

第五章 化工生产中的重要非金属元素
非金属及其化合物（章末图 · 深度版）
　氯及其化合物
  • 物理性质 　黄绿色、刺激性气味、密度大于空气 　可溶于水（1:2）
  • 与金属 　Na → NaCl（白烟） 　Cu → CuCl₂（棕黄烟） 　Fe → FeCl₃（棕红烟）
  • 与非金属 　H₂ 在 Cl₂ 中燃烧，苍白色火焰
  • 与水 　Cl₂ + H₂O ⇌ HCl + HClO
  • 与碱 　Cl₂ + 2NaOH → NaCl + NaClO + H₂O 　2Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O
  • 次氯酸及其盐 　HClO 弱酸、强氧化性、见光分解 　漂白粉有效成分 Ca(ClO)₂
  • 实验室制法 　MnO₂ + 4HCl(浓) →(Δ) MnCl₂ + Cl₂↑ + 2H₂O
　硫及其化合物
  • 硫单质 　淡黄色固体 　S + O₂ →(点燃) SO₂
  • 二氧化硫 　还原性：使氯水、酸性 KMnO₄ 褪色 　氧化性：与 H₂S 生成 S 　漂白性：可逆（化合） 　SO₂ + H₂O ⇌ H₂SO₃
  • 三氧化硫 　2SO₂ + O₂ ⇌(催化剂,Δ) 2SO₃ 　SO₃ + H₂O → H₂SO₄
  • 硫酸 　稀硫酸：酸的通性 　浓硫酸：吸水性、脱水性、强氧化性 　Cu + 2H₂SO₄(浓) →(Δ) CuSO₄ + SO₂↑ + 2H₂O
  • SO₄²⁻ 检验 　先加稀盐酸酸化，再加 BaCl₂
　氮及其化合物
  • 氮气 　N₂ + 3H₂ ⇌(催化剂,高温高压) 2NH₃
  • 氮的氧化物 　NO 无色、易被氧化 　NO₂ 红棕色 　3NO₂ + H₂O → 2HNO₃ + NO
  • 氨与铵盐 　NH₃ 极易溶于水，水溶液显碱性 　NH₄Cl →(Δ) NH₃↑ + HCl↑ 　铵根检验：加碱加热 + 湿润红色石蕊
  • 硝酸 　强氧化性 　Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O 　3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O
　无机非金属材料
  • 硅 　半导体材料 　SiO₂ + 4HF → SiF₄↑ + 2H₂O
  • 传统材料 　陶瓷：黏土 　玻璃：纯碱、石灰石、石英砂 　水泥：黏土和石灰石
　常见气体制备、净化与收集
  • 发生装置 　固固加热、固液常温、固液加热
  • 除杂与收集 　洗气、干燥、灼烧 　向上排空气 / 向下排空气 / 排水法
  • 安全装置 　防倒吸、防堵塞
　物质的检验、鉴别与推断
  • 常见离子检验 　Cl⁻：AgNO₃ + 稀硝酸 　SO₄²⁻：BaCl₂ + 盐酸 　CO₃²⁻：盐酸产生气体 　NH₄⁺：碱 + 湿润石蕊
　卤素
  • 递变性 　氧化性：Cl₂ > Br₂ > I₂
  • 置换 　Cl₂ + 2Br⁻ → Br₂ + 2Cl⁻ 　Cl₂ + 2I⁻ → I₂ + 2Cl⁻
  • 提取 　氧化 → 萃取 → 分液
第六章 化学反应与能量
化学反应与能量（章末图 · 深度版）
　化学能与热能
  • 本质 　键断裂吸热、键形成放热
  • 放热反应 　燃烧、中和、金属与酸、铝热
  • 吸热反应 　大多数分解 　Ba(OH)₂·8H₂O + NH₄Cl
　原电池
  • 构成条件 　两个活泼性不同的电极 　电解质溶液 　闭合回路 　自发氧化还原
  • 原理 　负极失电子（氧化） 　正极得电子（还原） 　电子经外电路由负极到正极
　化学反应速率
  • 表示 　v = Δc / Δt
  • 影响因素 　浓度、温度、压强、催化剂、表面积
　化学反应的限度
  • 可逆反应 　同一条件下正逆同时进行
